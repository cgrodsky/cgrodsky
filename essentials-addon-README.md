# Essentials (Minecraft Bedrock Add-On)

A small behavior pack with fun command shortcuts. Works on **Minecraft Bedrock**
(iPad, phone, Windows, console) — no MakeCode or PC required.

## Install
1. Download **`essentials.mcpack`**.
2. Open the file — choose **Open in Minecraft**. You'll see "Imported successfully".

## Use
1. Create or edit a world → **Behavior Packs** → activate **Essentials**.
2. Turn **Cheats: ON**, then play the world.
3. In chat, type any of:

| Command | What it does |
|---|---|
| `/function sudo` | Every player actually says a message (as if they did). |
| `/function fakechat` | Makes chat look like a random player said something. |
| `/function help` | Lists these commands in chat. |

## Customize
Open `essentials.mcpack` (it's a .zip) and edit the files in `functions/`:
- Change the **target selector**: `@a` all, `@r` random, `@p` nearest, `@s` you, or `@a[name="Bob"]`.
- Change the **message** text.
