# Golden Step Mod

A Minecraft Forge mod (1.20.1) that adds a **Golden Step Wand** — right-click to activate and every block you walk on turns into gold!

## Features

- **Golden Step Wand** item with enchanted glint
- Right-click to activate for **10 seconds**
- Converts all blocks in a 3x3 area beneath your feet into gold blocks
- **10 second cooldown** after the effect wears off
- Won't convert bedrock, air, or liquids
- Sound effects on activation/deactivation

## Crafting Recipe

```
    G
  B
S
```
- **G** = Gold Block
- **B** = Blaze Rod
- **S** = Nether Star

## Building

```bash
./gradlew build
```

The mod jar will be in `build/libs/`.

## Installation

1. Install Minecraft Forge 1.20.1
2. Place the built jar into your `mods` folder
3. Launch Minecraft
