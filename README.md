# Windows 12

A client-side Windows 12 simulation web app — boot animation, setup wizard,
desktop, taskbar, Microsoft Store, 11 games, Edge browser with custom Bank /
Amazon / Microsoft / YouTube / Discord sites, AI Copilot, Image Studio, and
more.

The app lives in [`windows12/`](./windows12) and is deployed to GitHub Pages
at **<https://cgrodsky.github.io/cgrodsky/>**.

## Code Quest

A client-side game-code maker in [`game/`](./game). Paste a **game code** to
drop straight into that exact level, switch to **Edit** to redesign it with a
tile painter, and the code updates live so you can copy and share your version.
Every level is stored entirely inside its code — no login, no server. Levels
also open from a `#code` URL, so play links are shareable too.

Play it at **<https://cgrodsky.github.io/cgrodsky/game/>**.
