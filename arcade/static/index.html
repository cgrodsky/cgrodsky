Keyboard-wedge readers type the card number for you — just tap and the card loads automatically, no backend needed.

When on, balance changes are also written to the chip so the card carries its own data. A central copy is still kept for the leaderboard. Needs a write-capable reader (ACR122U / MFRC522).

Prints via AirPrint. Use a thermal receipt printer that lists AirPrint (Star / Epson) for real roll receipts; any AirPrint printer works on paper. The barcode is a real, scannable Code 39 code of the claim number.
